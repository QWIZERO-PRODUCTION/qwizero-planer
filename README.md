# qwizero-planer — этап 1

Как получить exe:
1. Создай бесплатный репозиторий на github.com (кнопка New repository, любое имя, Private).
2. Загрузи в него всё содержимое этой папки (Add file → Upload files; папку .github тоже, она скрытая).
3. Открой вкладку Actions → Build Windows exe → Run workflow. Через 5–10 минут внутри запуска появится файл qwizero-planer-installer, скачай и запусти .exe.

Если сборка упала, открой запуск, скопируй текст ошибки и пришли мне.
